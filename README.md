# Automated Library Inventory System(ALIS) - Next.js Frontend web application

## Overview

The Automated Library Inventory System (ALIS) is a smart, AI-powered mechatronic solution designed to modernize library cataloguing by scanning book cover/front matter to retrieve relevant metadata about a book, such as:
- Author
- ISBN/ISSN
- Book title

This repository contains the Next.js frontend dashboard used for scanning, reviewing, editing, validating, and managing book metadata extracted via OCR and multimodal AI.
